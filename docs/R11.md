# R11: plain tool names, edit every match

Clients already group tools under the server's name ("symbia"), so the `symbia_` prefix on each tool repeats it. R11 drops it.

## Names

| Before | After |
|---|---|
| symbia_status | status |
| symbia_record | record |
| symbia_get | get |
| symbia_seal | seal |
| symbia_find | find |
| symbia_report | report |
| symbia_open | open |
| symbia_promote | promote |
| symbia_fs_read | read |
| symbia_fs_list | list |
| symbia_fs_search | search |
| symbia_fs_write | write |
| symbia_fs_edit | edit |
| symbia_exec | exec |
| symbia_job | job |

- `tools/list` returns only the new names.
- A call by an old name still reaches its tool, because a client may hold a tool list from before the rename. The record is written under the new name (`tool.exec`, body `"tool": "exec"`). Old names aren't listed and go away before 1.0.
- A job killed by a call names `job` as its killer.
- Records written before R11 keep their keys (`tool.symbia_exec`). `report` with `by: tool` counts them under the new names, so the totals don't split. Key-prefix finds see old and new keys as different keys.
- The Rust handler functions keep their names; the `#[tool(name = …)]` attribute sets the public name. Plain function names would collide with the `find`, `report` and `promote` helpers.

## edit: replace_all

`edit` replaces exactly one match. Renaming something across a file took one call per occurrence, each with enough context to be unique. With `replace_all: true`, `edit` replaces every non-overlapping match. It still refuses when there are none. The reply adds `replaced` (the count) and gives `line` for the first match.

## Tests

- r1: the listed names and annotations under the new names, with no name starting `symbia_`.
- A call by an old name reaches the tool and is recorded under the new name; an unknown `symbia_` name is still refused.
- `report` by tool merges `symbia_fs_read` and `read` into one group.
- `edit` with `replace_all`: replaces every match, reports the count, refuses on none, and leaves the file alone when refused.
- The existing tests call the tools by their new names.

## Docs

README, CHANGELOG and the tool descriptions use the new names. Earlier specs and reports keep the names they had.
